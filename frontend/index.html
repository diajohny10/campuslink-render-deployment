How CampusLink Works

Designed for zero-internet environments, enabling high-speed local file sharing and course management.

100% Offline Wi-Fi Network

Connect to local campus Wi-Fi access points without needing cellular data or active internet subscription.

Subject-Based Resource Hub

Teachers categorize notes and study materials by subject codes (CN, DS, DMS, ECON, UHV, COA) for easy student access.

Peer-to-Peer File Transfer

Transfer assignments directly to teachers or exchange study materials privately between students in seconds.

Privacy & Permission Matrix

Role-based security protects private student files while providing full audit notifications to course teachers.
